# Data Dictionary

## Kenyan Retail Dataset Generator

This document describes the datasets generated by the **Kenyan Retail Dataset Generator**.

The project generates synthetic retail data representing a Kenyan retail business environment. The datasets include master data, transactional data, inventory data, payments, and returns.

All records are synthetically generated and do not represent real individuals, companies, transactions, or businesses.

---

# Dataset Structure

The generated datasets are organized into three main categories:

```text
output/
│
├── master/
├── transaction/
└── raw/
```

## Master Data

Master datasets contain relatively stable business entities.

- Categories
- Suppliers
- Stores
- Customers
- Products
- Inventory

## Transaction Data

Transaction datasets represent business activities.

- Sales
- Sales Details
- Payments
- Returns

## Raw Data

Raw datasets contain intentionally introduced data quality issues for data cleaning and data engineering practice.

Examples include:

- Missing values
- Duplicate records
- Duplicate contact information
- Inconsistent capitalization
- Extra spaces
- Invalid email formats
- Phone number formatting differences
- Inconsistent categorical values
- Invalid or negative inventory quantities

# Data Relationships

The datasets can be connected using the following keys:

```text
Categories
    │
    └── CategoryID
            │
            └── Products
                    │
                    ├── ProductID ── Sales Details
                    │
                    ├── ProductID ── Inventory
                    │
                    └── ProductID ── Returns

Suppliers
    │
    └── SupplierID
            │
            └── Products

Customers
    │
    └── CustomerID
            │
            └── Sales

Stores
    │
    └── StoreID
            │
            ├── Sales
            └── Inventory

Sales
    │
    └── SaleID
            │
            ├── Sales Details
            ├── Payments
            └── Returns
```

# Important Notes

This dataset is synthetic.

The names, businesses, suppliers, transactions, contact information, and customer information are generated for educational and portfolio purposes.

The dataset should not be interpreted as representing real individuals, real businesses, or actual Kenyan retail transactions.

Derived analytical metrics are intentionally excluded where possible so that analysts and data professionals can perform their own calculations.
